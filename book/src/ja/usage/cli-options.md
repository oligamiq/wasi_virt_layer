# CLI オプション

`wasi_virt_layer` CLI は、モジュールのビルドおよび結合プロセスにおけるスタック管理の動作を構成するためのフラグを提供します。

## スタック構成

VFSモジュールとターゲットモジュールの両方に対して、スタックサイズとスロット数を構成できます。

*   **`--stack-size MODULE=SIZE`**
    特定のモジュールのスタックサイズを構成します。
    *   `MODULE`: モジュールの名前 (例: `vfs`, `target_name`)。
    *   `SIZE`: スタックのサイズ。読みやすさを向上させるため、`MiB`, `KiB`, `M`, `K` などのサフィックスをサポートしています (例: `--stack-size vfs=2MiB`)。

*   **`--stack-slots MODULE=COUNT`**
    スタックスロットの数を構成します。これは主に、スタックアリーナ内で複数のスロットが管理されるマルチメモリターゲットの実行に使用されます。
    *   `MODULE`: ターゲットモジュールの名前。
    *   `COUNT`: 割り当てるスロットの数。

### 制約とバリデーション

CLI はスタック構成に対して以下のバリデーションを強制します:
*   `--stack-slots` をVFSモジュールに適用しようとすると拒否されます（VFSは独自のスタックを管理するため）。
*   シングルメモリモードで動作している場合、`--stack-slots` は拒否されます。
*   シングルメモリモードにおいて、ターゲットのスタック分離が必要な場合、VFSスタックサイズ (`--stack-size vfs=...`) の構成が必須となります。
