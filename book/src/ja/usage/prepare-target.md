# ターゲットの準備

`prepare-target` コマンドは、標準的な WASIP1 Wasm モジュールを、ゼロコピー共有メモリ ABI をサポートするように変換するために使用されます。

## 使用法

```bash
wasi_virt_layer prepare-target <input_wasm> -o <output_wasm>
```

## 実行される処理

このコマンドは、Wasm モジュールに対して一連の変換を実行します。

1.  **ABI 関数のインポート**: 共有メモリ ABI 関数（`register`、`grow`、`get_lock_ptr`）のインポートを注入します。
2.  **グローバル変数の注入**: メタデータポインタとロックマネージャポインタを保持するためのグローバル変数を追加します。
3.  **初期化コード**: モジュールのエントリポイントに共有メモリ初期化ルーチンの呼び出しを注入します。
4.  **命令の置換**: すべての `memory.grow` 命令を、VFS 側の ABI への呼び出しに置き換えます。

## なぜ必要なのか

標準的な WASIP1 モジュールは、自身のプライベートな線形メモリを想定しています。マルチスレッドの仮想化環境で実行する場合、高コストなコピーを避けるために、複数のモジュール間で単一の線形メモリを共有する必要があります。`prepare-target` コマンドは、モジュールがこの共有メモリモデルと連携するようにパッチを適用します。
