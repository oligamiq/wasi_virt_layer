# wasi-virt-layer

This documentation is generated with mdBook and kept entirely under the `book/` directory.

## What I included

- Minimal mdBook scaffold: `book.toml`, `src/SUMMARY.md`, `src/index.md`
- A basic theme override in `theme/stylesheet.css`

To build the book locally, install mdbook (`cargo install mdbook` or via your package manager) and run `mdbook build book`.
