# Pooled Worker Start Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `VirtualThreadPool` worker reuse run the target Wasm start-section initialization before each logical `wasi_thread_start` invocation.

**Architecture:** Keep the existing one-time synthesized module `_start` behavior unchanged. Fix only the target-specific thread-start import path in `post_combine.rs` by replacing direct import-to-export rebinding with a generated wrapper that calls the target runtime start function, then calls the original target `wasi_thread_start(thread_id, start_arg)`.

**Tech Stack:** Rust 2024, `wasmparser`, `wasm-encoder`, `cargo test`, Deno-backed CLI integration tests.

## Global Constraints

- Rust edition is 2024; minimum rustc is 1.89.0.
- Do not modify unrelated dirty worktree changes, especially `wasi_virt_layer/src/wasi/file/dynamic/lfs.rs` unless explicitly asked.
- Keep import/export names in sync across generator stages when touching ABI naming.
- Preserve `Debug*` generators unless intentionally removed.
- Use TDD: keep the committed RED integration test as the first proof, then make it GREEN with the minimal implementation.
- Do not re-run one-time combined `_start` for logical pool thread starts; only run the target runtime start for the target whose `wasi_thread_start` is about to run.

#[test]
fn target_wasi_thread_start_import_is_wrapped_not_directly_rebound() -> eyre::Result<()> {
    let input = module_with_target_wasi_thread_start_import_export_and_runtime_start();
    let mut pass = PostCombineStreamPass::new(
        "test_vfs".to_string(),
        vec!["target".to_string()],
        vec![1, 3],
        true,
    );

    let output = pass.run(&input)?;

    let mut caller_calls = Vec::new();
    let mut import_count = 0u32;
    let mut caller_index = None;
    let mut function_index = import_count;

    for payload in wasmparser::Parser::new(0).parse_all(&output) {
        match payload? {
            wasmparser::Payload::ImportSection(section) => {
                for import in section {
                    for (_, import) in import?.into_iter() {
                        if matches!(import.ty, wasmparser::TypeRef::Func(_)) {
                            import_count += 1;
                            function_index += 1;
                        }
                    }
                }
            }
            wasmparser::Payload::ExportSection(section) => {
                for export in section {
                    let export = export?;
                    if export.name == "target_wasi_thread_start_caller" {
                        caller_index = Some(export.index);
                    }
                }
            }
            wasmparser::Payload::CodeSectionEntry(body) => {
                let current = function_index;
                function_index += 1;
                if Some(current) == caller_index {
                    for op in body.get_operators_reader()? {
                        if let wasmparser::Operator::Call { function_index } = op? {
                            caller_calls.push(function_index);
                        }
                    }
                }
            }
            _ => {}
        }
    }

    assert_eq!(caller_calls.len(), 1);
    assert_ne!(
        caller_calls[0],
        caller_index.expect("caller export should exist"),
        "caller must call a generated wrapper, not itself"
    );

    Ok(())
}
```

fn module_with_target_wasi_thread_start_import_export_and_runtime_start() -> Vec<u8> {
    let mut module = Module::new();

    let mut types = TypeSection::new();
    let thread_start_type = types.len();
    types
        .ty()
        .function([wasm_encoder::ValType::I32, wasm_encoder::ValType::I32], []);
    let void_type = types.len();
    types.ty().function([], []);
    module.section(&types);

    let mut imports = ImportSection::new();
    imports.import(
        "wasip1-vfs",
        "__wasip1_vfs_target_wasi_thread_start",
        EntityType::Function(thread_start_type),
    );
    module.section(&imports);

    let mut functions = FunctionSection::new();
    functions.function(void_type);
    functions.function(thread_start_type);
    functions.function(void_type);
    module.section(&functions);

    let mut exports = ExportSection::new();
    exports.export("__flesh_vfs_start", ExportKind::Func, 1);
    exports.export("__wasip1_vfs_target__start", ExportKind::Func, 1);
    exports.export("__wasip1_vfs_target_wasi_thread_start", ExportKind::Func, 2);
    exports.export("target_wasi_thread_start_caller", ExportKind::Func, 3);
    module.section(&exports);

    let mut code = CodeSection::new();
    let mut runtime_start = wasm_encoder::Function::new(vec![]);
    runtime_start.instruction(&wasm_encoder::Instruction::End);
    code.function(&runtime_start);

    let mut target_thread_start = wasm_encoder::Function::new(vec![]);
    target_thread_start.instruction(&wasm_encoder::Instruction::End);
    code.function(&target_thread_start);

    let mut caller = wasm_encoder::Function::new(vec![]);
    caller.instruction(&wasm_encoder::Instruction::I32Const(7));
    caller.instruction(&wasm_encoder::Instruction::I32Const(11));
    caller.instruction(&wasm_encoder::Instruction::Call(0));
    caller.instruction(&wasm_encoder::Instruction::End);
    code.function(&caller);
    module.section(&code);

    module.finish()
}
```
